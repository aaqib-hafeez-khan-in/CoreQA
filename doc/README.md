## 📸 Screenshots

All project screenshots are stored in the `screenshots/` directory. These images are referenced in the main README.md file.

### Required Screenshots

See [SCREENSHOTS.md](SCREENSHOTS.md) for detailed guidelines on:
- Required screenshots
- Dimensions and specifications
- Quality standards
- Capture tools and techniques

### Adding Screenshots

1. Capture screenshots according to guidelines in `SCREENSHOTS.md`
2. Optimize images (compress to reduce file size)
3. Save with exact filenames in `screenshots/` folder
4. Verify they display correctly in `README.md`
